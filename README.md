# بنك أسئلة سمنار التنمية المهنية

بنك أسئلة اختيار من متعدد لمقرر **سمنار التنمية المهنية**، يغطي المواضيع الثلاثة:

1. مهنة التعليم ومكانة المعلم
2. تكوين المعلم
3. التنمية المهنية للمعلم

## المزايا

- 241 سؤالاً موزعة على المواضيع الثلاثة
- اختيار الموضوع وعدد الأسئلة قبل بدء الاختبار
- خلط الأسئلة والخيارات في كل محاولة
- تصحيح فوري مع شرح مختصر لكل إجابة
- نتيجة نهائية مع إمكانية إعادة الأخطاء فقط
- يعمل على الجوال والكمبيوتر، ويدعم الوضع الليلي

## التشغيل

افتح ملف `index.html` في المتصفح مباشرة، أو فعّل GitHub Pages للمستودع.
